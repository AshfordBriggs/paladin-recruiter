The **Calls** page lists every call you've made or taken, newest first.
Search it to find one call and open its summary and transcript.

1. Select **Calls** in the top bar.
2. To narrow the list, type a name, part of a number, or an outcome in the
   search box.
3. Select the call. Its summary page opens.
4. If the call is older than the list goes, scroll to the bottom and select
   **Load 100 more**.

Each row shows the candidate, the number, the direction (**in** or **out**),
when it happened, how long it lasted, the outcome and whether the summary is
ready. Calls placed from the Paladin Dialer are marked **mobile**.

## What happens next

The summary page shows the summary, key points, action items and the full
transcript. See [After the call](../../calls/after-the-call/).

A call that's still going appears in a card above the list, marked **Call in
progress**. Select it to watch the call live.

To see only one candidate's calls, open the candidate's page and look under
**Call History**.

## If something goes wrong

- **"No calls match" your search.** Search looks at candidate names, numbers
  and outcomes. Numbers match only as they're stored, so try the last four
  digits. For an outcome, type one word, such as `scheduled` or `rejected`.
- **The page says "No calls yet."** Calls show up here once you've made or
  taken one through Paladin. Calls made from your phone's own dialer don't go
  through Paladin.
- **The call shows "Unknown caller."** The number isn't on any candidate. To
  make one, see [After the call](../../calls/after-the-call/).
