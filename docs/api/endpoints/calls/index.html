Endpoints

Calls

Calls, transcripts and summaries.

Calls are server-wide: every recruiter’s calls, except calls with a candidate the key can’t see. Calls with callers nobody has named yet are included, with “Unknown Caller” and the number as the candidate’s name.

List calls

Section titled “List calls”
GET/api/v1/callsread

Newest first, by start time.

Parameter Description
job_id Only calls about this job.
candidate_id Only calls with this candidate.
opportunity_id Only calls about this opportunity.
recruiter_id Only this recruiter’s calls.
since Only calls that started at or after this UTC time.
until Only calls that started before this UTC time. Must be after since.
limit, offset See Paging.

Tip

Calls placed from a phone rather than from the candidate’s page often have no job or opportunity_id. To find every call with a candidate about a job, filter by candidate_id and match the job yourself.

Field Description
direction outbound or inbound. null on older calls.
origin dashboard (started from Paladin), disa (placed from the Paladin Dialer), or passive_inbound / passive_outbound (a call to or from a Paladin number that wasn’t started in Paladin).
call_type candidate_screen, hiring_manager_hsk (hiring-manager intake), candidate_debrief or recruiter.
connected true when someone answered and talked. See below.
started_at When the call was placed. Not proof that anyone answered.
duration_seconds Length as the phone system recorded it.
outcome Set by the recruiter after the call: scheduled_next, forwarded_to_client, rejected, callback_requested or no_answer. Usually null.
summary_status pending, complete or failed. null when the call has no transcript.

What connected means. A call is connected when it has a start time, a duration above zero, and an outcome other than no_answer. A start time alone isn’t enough, because the phone system sets it as soon as the call is placed, before anyone picks up. Paladin’s Insights page and the metrics use the same rule.

One call, with the same fields.

Get a call summary

Section titled “Get a call summary”
GET/api/v1/calls/{id}/summaryread
  • summary is Markdown. Render it, or strip the formatting for plain text.
  • While the summary is being written, status is pending, summary is null and the lists are empty. Check again in a minute.
  • A call with no transcript answers 404.

Get a call transcript

Section titled “Get a call transcript”
GET/api/v1/calls/{id}/transcriptread
  • speaker is recruiter or candidate, or unknown when Paladin couldn’t tell.
  • While the call is live, stage is during_call and more turns keep arriving. Check again until it’s final.
  • Keep the turns in the order given. Don’t re-sort them by at.
  • A call answers 404 here until its first turn is transcribed.
