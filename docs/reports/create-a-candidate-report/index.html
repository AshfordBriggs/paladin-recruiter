Reports

Create a candidate report

A write-up for the hiring manager, from a call or from what's on file.

A candidate report is a short write-up of one candidate for one job, ready for the hiring manager. You don’t need a call first: Paladin builds it from whatever is on the opportunity, such as a phone screen transcript, notes, documents and call summaries.

Before you start

The candidate must be yours, or you must be an admin.

  1. Open Candidates and select the candidate.
  2. Under Opportunities, select the job you want the report for. The opportunity page opens.
  3. Under Reports, select Generate candidate report. A dialog lists what the report will use.
  4. Select Generate report. The report fills in as Paladin writes it. You can leave the page; it keeps going.
  5. Under Recruiter assessment, pick Strong match, Possible match or Gaps to discuss. AI suggests marks Paladin’s pick. The report doesn’t show an assessment until you choose one.
  6. To change the wording, select Edit, click into the report and type, then select Save. Or type what you want in the Revise with AI box, for example “shorter”, and choose Keep or Discard.

To report on one call only, select From latest call in step 3 instead.

Tip

On the candidate’s page, the Generate report button on each opportunity row does the same as steps 2 to 4.

What happens next

Section titled “What happens next”

The new report is a Brief: about half a page the hiring manager can scan. For a longer one, select Style: Brief at the top of the report and choose Executive (one page) or Full. That makes a new report and keeps the old one.

Every report is listed under Reports on the opportunity page, newest first. Each edit is saved as a version; select History to see them and Restore an older one. To take a copy with you, select Download DOCX or Print / Save PDF.

If something goes wrong

Section titled “If something goes wrong”
  • The dialog says “There is nothing on this opportunity yet”. You can still generate, but the report will be thin. Attach a phone screen transcript or notes on the opportunity page first for a better one.
  • The report says it is a pre-screen assessment. Nobody has spoken to the candidate through Paladin and no screen transcript is attached. Call the candidate, or attach the transcript, then generate again.
  • You see “Generated while the call was active”. The call hadn’t ended. Select Regenerate once it has.
  • You see “Generation continues in the background”. The connection dropped but the report is still being written. Check Reports on the opportunity page in a minute or two.
  • You see “Only the candidate’s owner or an admin can change this report.” Ask the candidate’s owner or an admin to make the change.

Note

If your team recruits for its own company, Paladin says Roles instead of jobs. The steps are the same.
